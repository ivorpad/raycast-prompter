# Prompter Changelog

## [Readable previews, prompts in root search] - 2026-09-03

- Previews render the text as markdown. Escaping every punctuation mark showed the backslashes in
  Raycast, and `\(` `\)` switched it into LaTeX
- Saving a new prompt offers **Add to Root Search**: a Quicklink under the prompt's name, so it runs
  from root search like the built-in commands. Also on each custom prompt in the list (`⌘⇧A`)

## [Initial Version] - 2026-09-02

- Six prompt commands: Fix Errors, Make Shorter, Make Longer, More Professional, More Casual, For Slack
- OpenAI, OpenRouter, Anthropic, or any OpenAI-compatible server; models fetched from the API
- Input from typed text, the selection, or the clipboard
- Preview with paste/copy, or paste/copy directly
- Prompts command: edit built-ins, add, duplicate and delete your own, edit the shared rules
